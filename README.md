# Задание 1

## Задача 1.

### Текст задачи

Реализовать класс `Time`, содержащий два поля: short int hours — часы и short int minutes — минуты. В классе необходимо предусмотреть поля, свойства, не менее трёх конструкторов и перегрузку оператора вывода для отображения полей объекта. Все исходные данные вводятся с клавиатуры и проверяются на корректность. В главной функции необходимо продемонстрировать работу реализованных методов и конструкторов.

### Алгоритм решения

Создаём класс `Time` с двумя закрытыми полями `hours_` и `minutes_`. Для получения их значений реализуем методы `hours()` и `minutes()`, а для изменения — `set_hours()` и `set_minutes()`. В сеттерах проверяем корректность данных: часы должны находиться в диапазоне от 0 до 23, минуты — от 0 до 59. При недопустимом значении выбрасываем исключение `std::out_of_range`.

Реализуем три конструктора: без параметров, устанавливающий время `00:00`; с одним параметром, принимающий часы и устанавливающий минуты в ноль; с двумя параметрами, принимающий часы и минуты. Для исключения повторения кода первые два конструктора обращаются к конструктору с двумя параметрами.

Перегружаем оператор `<<`, чтобы выводить объект в формате `ЧЧ:ММ`, включая ведущие нули. Проверку ввода с клавиатуры выполняем с помощью функции `ReadInt()`: если введено нецелое число или значение вне допустимого диапазона, программа повторно запрашивает данные. В `main()` создаём объекты всеми тремя способами, изменяем значения через сеттеры и выводим результаты с помощью геттеров и перегруженного оператора.

### Тестирование

При создании объекта без параметров получаем `00:00`. Конструктор с одним параметром при вводе `12` создаёт время `12:00`. Конструктор с двумя параметрами при вводе часов `14` и минут `35` создаёт время `14:35`. После изменения часов и минут через сеттеры на `14` и `25` получаем `14:25`. При вводе неверных данных, например `25` часов или `75` минут, программа сообщает об ошибке и предлагает повторить ввод.

*Здесь будет скриншот проверки конструкторов, геттеров, сеттеров и ввода данных.*

## Задача 2.

### Текст задачи

Для класса `Time` реализовать вычитание переменной типа `Time`, учитывая, что возможен переход в предыдущие сутки. Результат должен быть типа `Time`.

### Алгоритм решения

Создаём метод `Subtract(const Time& other)`, который принимает второй объект времени и возвращает новый объект `Time`. Чтобы выполнить вычитание, переводим оба значения в минуты с помощью метода `ToMinutes()`: умножаем часы на 60 и прибавляем минуты. Затем вычитаем полученные количества минут.

Для обработки перехода в предыдущие сутки используем метод `FromMinutes()`. В нём нормализуем результат по модулю 1440, поскольку в сутках 24 × 60 = 1440 минут. Чтобы отрицательный результат также преобразовывался правильно, применяем выражение `(total_minutes % 1440 + 1440) % 1440`. После этого находим часы целочисленным делением на 60, а минуты — остатком от деления на 60. Возвращаем новый объект `Time`, не изменяя исходные объекты.

# Задание 2

## Задача 1.

### Текст задачи

Для класса `Time` из первого задания реализовать перегрузку следующих операций согласно варианту 7:

- **Унарные операции:** `++` — добавление одной минуты к объекту типа `Time`; `--` — вычитание одной минуты из объекта типа `Time`.
- **Операции приведения типа:** `int` (неявная) — результатом является количество минут, в которое переводится время; `bool` (явная) — результат `true`, если время не равно `00:00`, и `false` в противном случае.
- **Бинарные операции:** `< Time t` — сравнение двух объектов по количеству минут, результат `true`, если левый операнд меньше правого; `> Time t` — сравнение двух объектов по количеству минут, результат `true`, если левый операнд больше правого.

### Алгоритм решения

Перегружаем префиксные и постфиксные операторы `++` и `--`. Префиксные операторы переводят текущее время в минуты, прибавляют или вычитают одну минуту, преобразуют результат обратно в `Time` и возвращают ссылку на изменённый объект. Постфиксные операторы сначала сохраняют копию предыдущего значения, затем вызывают соответствующий префиксный оператор и возвращают сохранённую копию. Переходы через полночь обрабатываются методом `FromMinutes()`.

Реализуем неявное преобразование `operator int()`, возвращающее общее количество минут с начала суток через `ToMinutes()`. Явное преобразование `operator bool()` возвращает результат проверки `ToMinutes() != 0`. Для сравнения реализуем операторы `<` и `>`, которые переводят оба объекта в минуты и сравнивают полученные числа.

В главной функции создаём копии исходного объекта и демонстрируем все четыре формы инкремента и декремента. Затем выводим результат преобразования в `int`, явного преобразования в `bool` и сравнения двух объектов. Для удобства чтения логические значения выводятся с помощью `std::boolalpha`.
